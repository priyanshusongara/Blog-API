🚀 Blog API

A RESTful API built using Django REST Framework

📌 About This API

This is a production-ready Blog API that allows users to register, authenticate using JWT, create posts, and add comments.

⚡ API Endpoints

Register:

POST /api/users/register/

Login:

POST /api/token/

Posts:

GET /api/posts/

POST /api/posts/

Comments:

GET /api/comments/

POST /api/comments/

🛠 How to Use

1. Register a user

2. Login to get JWT token

3. Use token in Authorization header

4. Create posts & comments
